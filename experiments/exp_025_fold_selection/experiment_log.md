# exp_025: Top-3 Fold Selection with Rank-Based Weights

> 実施日: 2026-01-30

## 仮説

**B5が効かなかった根本原因:**
- 容量不足ではなく、**学習ダイナミクス/表現の種類がボトルネック**
- 0.44039は「B4 + Aug + TTA」のほぼ限界値
- **残り+0.020は後処理やTTA積み増しでは届かない**

**Fold選別の理論:**
- SSIMタスクの本質: 「平均的に良い」より「一貫して同じ構造を出す」
- 弱foldは平均SSIMを0.01しか下げないが、**局所構造を1回壊す**
- → **Fold数を減らす = ノイズ源を消す**

## 変更点 (exp_023ベース)

### 推論時アンサンブル

| 設定 | exp_023 | exp_025 |
|------|---------|---------|
| 使用fold数 | 全5 fold | **上位3 fold** |
| 重み付け | softmax (temperature=5) | **rank-based (1.0, 0.7, 0.4)** |
| TTA | 中央値 | 中央値 (変更なし) |

### Configパラメータ

```python
n_folds_ensemble = 3              # 上位3 foldのみ使用
fold_rank_weights = [1.0, 0.7, 0.4]  # Rank-based重み (softmax禁止)
```

## なぜsoftmaxを禁止するか

- softmaxは差を均してしまう
- rank-basedは明確な序列を維持
- 最良foldの影響力を確保

## 期待効果

- LB +0.005〜0.010 (0.44039 → 0.445〜0.450)
- 0.445を超えたら戦場が変わる
